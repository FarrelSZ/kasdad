Slide ini mendaftar pilihan umum untuk tiap komponen (representation, evaluation, optimization) dan memberi contoh memilih satu dari tiap kolom untuk klasifikasi pembelian komputer memakai *Multilayer Perceptron*.

**Analogi.** Menu paket makan: satu pilihan dari kolom “bentuk model”, satu dari kolom “cara menilai”, dan satu dari kolom “cara mencari”. Kombinasi yang berbeda menghasilkan algoritma yang berbeda.

**Representation (bentuk model)**

| Istilah | Arti sederhana |
| --- | --- |
| Instance-based | Memprediksi dengan membandingkan data baru ke contoh yang disimpan (misalnya k-nearest neighbor: lihat tetangga terdekat) |
| Hyperplane | Bidang datar pemisah: garis pada 2 dimensi, bidang pada 3 dimensi (regresi linear, logistik, SVM) |
| Decision tree | Pohon pertanyaan ya atau tidak, seperti pada slide 43 |
| Set of rules | Kumpulan aturan “jika-maka” |
| Neural networks | Lapisan-lapisan neuron tiruan yang saling terhubung |
| Graphical models | Variabel sebagai simpul dan hubungan antarvariabel sebagai garis, disertai peluang (misalnya jaringan Bayes, HMM) |

**Evaluation (cara menilai)**

| Istilah | Arti sederhana |
| --- | --- |
| Accuracy | Persentase prediksi yang benar |
| Precision, Recall | Ketepatan dan kelengkapan pada prediksi kelas positif (dijelaskan di bawah) |
| Mean Avg Precision | Rata-rata ketepatan pada tugas peringkat, misalnya mesin pencari |
| Mean Average Error | Rata-rata besar selisih; umumnya disebut Mean Absolute Error (MAE) |
| Mean Square Error | Rata-rata kuadrat selisih (MSE); selisih besar dihukum lebih berat |
| K-L divergence | Ukuran seberapa berbeda dua distribusi peluang |
| Likelihood | Seberapa masuk akal data yang teramati menurut model dengan parameter tertentu |

**Optimization (cara mencari)**

| Istilah | Arti sederhana |
| --- | --- |
| Greedy search | Pada tiap langkah memilih yang tampak terbaik saat itu, tanpa menoleh ke belakang |
| Branch and bound | Pencarian sistematis yang memangkas cabang yang pasti tidak lebih baik dari yang terbaik sejauh ini |
| Gradient descent | Menyesuaikan parameter sedikit demi sedikit ke arah yang paling menurunkan kesalahan |
| Quasi-Newton | Mirip gradient descent, tetapi memakai perkiraan kelengkungan untuk langkah yang lebih cerdas |
| Linear programming | Mengoptimalkan tujuan linear dengan batasan linear |
| Quadratic programming | Mengoptimalkan tujuan kuadrat dengan batasan linear (dipakai melatih SVM) |

**Rumus dan cara memakainya (contoh tambahan)**

Akurasi:

```latex
\text{accuracy} = \frac{\text{jumlah prediksi benar}}{\text{jumlah seluruh prediksi}}
```

Contoh: 90 benar dari 100 prediksi berarti akurasi 90%. Waspada: bila 99% transaksi sah, model yang selalu menjawab “sah” berakurasi 99% tetapi tidak berguna. Karena itu precision dan recall penting pada data tak seimbang (*imbalanced*, slide 50).

Precision dan recall (TP = positif yang terdeteksi dengan benar, FP = salah menandai positif, FN = positif yang terlewat):

```latex
\text{precision} = \frac{TP}{TP + FP} \qquad \text{recall} = \frac{TP}{TP + FN}
```

Langkah: (1) hitung TP, FP, FN; (2) precision: dari semua yang ditandai, berapa yang benar; (3) recall: dari semua yang sebenarnya positif, berapa yang ditemukan. Contoh: model menandai 10 transaksi sebagai penipuan, 8 benar (TP = 8, FP = 2); ada 16 penipuan sebenarnya (FN = 8). Precision = 8/10 = 0,8; recall = 8/16 = 0,5.

MAE dan MSE:

```latex
\text{MAE} = \frac{1}{n}\sum_{i=1}^{n} |y_i - \hat{y}_i| \qquad \text{MSE} = \frac{1}{n}\sum_{i=1}^{n} (y_i - \hat{y}_i)^2
```

Keterangan: yᵢ nilai sebenarnya, ŷᵢ prediksi, n jumlah data. Langkah: (1) hitung selisih tiap data; (2) MAE: ambil nilai mutlak lalu rata-ratakan; MSE: kuadratkan lalu rata-ratakan. Contoh: selisih 2, −2, 3 memberi MAE = (2 + 2 + 3) / 3 ≈ 2,33 dan MSE = (4 + 4 + 9) / 3 ≈ 5,67.

Gradient descent:

```latex
\theta \leftarrow \theta - \eta \, \nabla L(\theta)
```

Keterangan: θ = parameter model, L(θ) = kesalahan (*loss*), ∇L = gradien (arah yang paling menaikkan kesalahan), η = laju belajar (besar langkah). Karena gradien menunjuk arah naik, kita mengurangkannya agar turun. Contoh: L(θ) = (θ − 3)², sehingga gradien = 2(θ − 3). Mulai dari θ = 0 dan η = 0,1:

1. Gradien = 2 × (0 − 3) = −6.
2. θ baru = 0 − 0,1 × (−6) = 0,6.
3. Gradien baru = 2 × (0,6 − 3) = −4,8; θ = 0,6 − 0,1 × (−4,8) = 1,08.
4. Diulang, θ makin mendekati 3, yaitu titik terendah kesalahan.

**Contoh soal**

1. Model menandai 10 transaksi sebagai penipuan, 8 benar. Ada 16 penipuan sebenarnya. Hitung precision dan recall.
   - **Pembahasan:** precision = 8/10 = 0,8; recall = 8/16 = 0,5.
2. Nilai sebenarnya \[10, 20, 30\], prediksi \[12, 18, 33\]. Hitung MAE dan MSE.
   - **Pembahasan:** selisih mutlak 2, 2, 3, jadi MAE = 7/3 ≈ 2,33. Kuadratnya 4, 4, 9, jadi MSE = 17/3 ≈ 5,67.
3. Lakukan satu langkah gradient descent untuk L(θ) = (θ − 3)², dengan θ = 0 dan η = 0,1.
   - **Pembahasan:** gradien = 2(0 − 3) = −6; θ baru = 0 − 0,1 × (−6) = 0,6.
