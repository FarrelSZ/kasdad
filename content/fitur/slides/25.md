### Slide 25 – Min-Max Scaling

Slide ini memperkenalkan *min-max scaling*: nilai sebuah fitur diubah skalanya ke rentang 0 sampai 1 dengan rumus (x − min) / (max − min), dicontohkan pada kolom pengeluaran (*Expenses*).

**Analogi.** Nilai ujian sekelas. Nilai terendah 40 dianggap 0, nilai tertinggi 90 dianggap 1, sehingga nilai 65 tepat di tengah: (65 − 40) / (90 − 40) = 0,5. Angka aslinya berganti menjadi “posisi relatif di antara yang terendah dan tertinggi”.

**Isi slide**

- “The simplest method for rescaling the range of features in \[0, 1\]:” Metode paling sederhana untuk mengubah skala rentang fitur ke \[0, 1\]. Notasi \[0, 1\] berarti dari 0 sampai 1, kedua ujung termasuk.
- Rumus di bawahnya (lihat bagian rumus).
- Tulisan merah di dekat panah: “Min-max scaling on Expenses”, yaitu penskalaan min-max pada kolom *Expenses*.

**Gambar dan diagram, bagian demi bagian**

Tabel kiri berkolom *Cust#* (nomor pelanggan), *Credit Rating* (peringkat kredit), dan *Expenses* (pengeluaran); panah biru; tabel kanan berkolom sama, tetapi kolom *Expenses* sudah berisi hasil skala. Isi keduanya saya gabungkan (angka mengikuti penulisan slide):

Cara membaca:

1. Kolom *Credit Rating* tidak berubah (18, 20, 21, 19, 19, 20); hanya *Expenses* yang diskalakan, sesuai tulisan merah.
2. Cari nilai terkecil dan terbesar *Expenses*: min = 1.000.000 (pelanggan 1) dan max = 4.000.000 (pelanggan 5). Selisihnya, max − min = 3.000.000, adalah lebar rentang.
3. Hitung tiap pelanggan. Pelanggan 1: (1.000.000 − 1.000.000) / 3.000.000 = 0. Pelanggan 2: 1.000.000 / 3.000.000 = ⅓ ≈ 0,33. Pelanggan 3: 500.000 / 3.000.000 = ⅙ ≈ 0,17. Pelanggan 4: 1.500.000 / 3.000.000 = 0,50. Pelanggan 5: 3.000.000 / 3.000.000 = 1. Pelanggan 6: 1.200.000 / 3.000.000 = 0,40. Semuanya cocok dengan tabel kanan (hasil periksa saya).
4. Hasilnya: nilai terkecil menjadi tepat 0, nilai terbesar tepat 1, dan nilai lain berada di antaranya menurut posisi relatifnya. Urutan antarpelanggan tidak berubah.
5. Slide tidak menjelaskan mengapa *Credit Rating* tidak ikut diskalakan; ia hanya contoh satu kolom (tafsiran saya).

**Rumus, langkah demi langkah**

```latex
x' = \frac{x - \min(x)}{\max(x) - \min(x)}
```

Dengan x = nilai asli, min(x) = nilai terkecil pada kolom itu, max(x) = nilai terbesar pada kolom itu, dan x′ (dibaca “x aksen”) = nilai hasil.

*Asal-usul.* Rumus ini hasil dua langkah sederhana:

1. **Geser.** Kurangi setiap nilai dengan nilai terkecil: x − min(x). Kini nilai terkecil menjadi 0 dan nilai terbesar menjadi max(x) − min(x).
2. **Kecilkan.** Bagi hasilnya dengan lebar rentang, max(x) − min(x). Kini nilai terbesar menjadi tepat 1.

Sesudah dua langkah itu semua nilai ada di antara 0 dan 1, dan urutannya sama seperti semula. Contoh pada slide: untuk pelanggan 2, x = 2.000.000, jadi (2.000.000 − 1.000.000) / (4.000.000 − 1.000.000) = ⅓ ≈ 0,33.

Penskalaan ini sudah dibahas bersama *z-score* di Bagian 4, slide 35; slide 25 memberi contoh penerapannya.

**Istilah penting**

- **Penskalaan (*scaling*)**: mengubah rentang nilai suatu fitur tanpa mengubah urutannya.
- ***Min-max scaling***: penskalaan yang memetakan nilai terkecil ke 0 dan terbesar ke 1.
- **Rentang \[0, 1\]**: semua nilai di antara 0 dan 1; kurung siku berarti kedua ujung termasuk.
- **min(x) dan max(x)**: nilai terkecil dan nilai terbesar pada kolom x.
- ***Credit Rating***, ***Expenses***, ***Cust#***: peringkat kredit, pengeluaran, dan nomor pelanggan.

**Mengapa penting.** Fitur sering punya satuan dan besaran yang sangat berbeda (peringkat 18 sampai 21 berbanding pengeluaran jutaan). Tanpa penyamaan skala, fitur berangka besar dapat menenggelamkan fitur berangka kecil pada algoritma yang memakai jarak atau selisih nilai.

(4) Sepengetahuan saya, min dan max sebaiknya dihitung dari data latih lalu dipakai kembali pada data baru; nilai baru di luar rentang itu dapat menghasilkan angka di luar \[0, 1\] (contoh soal 3). Slide tidak membahasnya.

**Contoh soal**

1. Skalakan *Credit Rating* 18, 20, 21, 19, 19, 20 dengan *min-max*.
   - **Pembahasan:** min = 18, max = 21, lebar rentang 3. Hasilnya (18 − 18) / 3 = 0; (20 − 18) / 3 ≈ 0,67; (21 − 18) / 3 = 1; (19 − 18) / 3 ≈ 0,33; 0,33; 0,67.
2. Skalakan 10, 20, dan 50 dengan *min-max*.
   - **Pembahasan:** min = 10, max = 50, lebar rentang 40. Hasilnya 0 / 40 = 0; 10 / 40 = 0,25; 40 / 40 = 1.
3. Sebuah pelanggan baru memiliki pengeluaran 5.000.000. Berapa hasil skalanya bila memakai min dan max dari slide 25?
   - **Pembahasan:** (5.000.000 − 1.000.000) / 3.000.000 ≈ 1,33. Hasilnya melewati 1 karena nilai baru lebih besar daripada max yang lama.
4. Mengapa kolom *Expenses* mendominasi hitungan jarak antarpelanggan bila tidak diskalakan?
   - **Pembahasan:** angkanya berukuran jutaan, sedangkan *Credit Rating* hanya belasan. Selisih *Expenses* antarpelanggan jauh lebih besar daripada selisih rating, sehingga hampir seluruh jarak ditentukan oleh *Expenses*. Penskalaan menyamakan keduanya ke rentang 0 sampai 1.
